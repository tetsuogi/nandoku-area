# 難読地名帳

初見ではまず読めない日本各地の地名を、クイズとカードで覚える Web アプリ。

## 機能

- **一覧**：都道府県別に表示・検索。「読みを隠す」で自分テストもできる
- **制覇マップ**：都道府県別のマスター率（「覚えた」を押した地名の割合）を日本地図で色分け。県をタップすると県ごとの成績と地名の一覧
- **カード**：漢字 ⇄ 読みのフラッシュカード
- **クイズ**：漢字 → 読み（4択／入力）、読み → 漢字、地名 → 都道府県、書き取り（指で書いて答えを見て、書けた／書けなかったを自分で選ぶ）。地方・都道府県・難しさ・種類で絞り込める
- **復習**：間違えた問題だけを再出題（正解するとリストから外れる）
- **覚えた**：自己申告のチェック。覚えた地名はクイズに出る確率が1/5になり、間違えると外れる

ログインした人だけが使えます。覚えた地名・成績・復習リストはアカウントごとに Supabase に保存され、本人以外には見えません。

## ファイル

| ファイル | 内容 |
|---|---|
| `data.js` | 地名データ（`tools/build_data.py` が生成。直接編集しない） |
| `app.js` | アプリ本体 |
| `style.css` | 見た目 |
| `config.js` | Supabase の接続情報 |
| `supabase/schema.sql` | 進捗を保存するテーブル |
| `tools/places.txt` | 地名の元データ |
| `tools/build_data.py` | 元データを Wikipedia と照合して `data.js` を作るスクリプト |

## 地名を追加・修正するとき

1. `tools/places.txt` に1行追加する（書き方はファイル冒頭のコメント）
2. `python3 tools/build_data.py` を実行する
   - 各地名の Wikipedia 記事の冒頭にある読みと照合し、一致したものだけが `data.js` に入る
   - 一致しないものは「NG」として表示されるので、読みか記事名を直す
   - 同じ都道府県に同じ読みの地名（例：枝幸町と江差町）があると止まるので、最後の「地域」の列に見分けるための地域（例：道北・宗谷地方）を書く
3. `index.html` の `?v=…` を新しくしてから公開する

## Supabase の準備（初回だけ）

ダービー馬暗記帳と同じプロジェクトを使い、テーブルだけ追加する。
Supabase の SQL Editor で `supabase/schema.sql` を実行する。アカウントはダービー馬暗記帳と共通。

## 手元での確認

```
python3 -m http.server 8766
```

`http://localhost:8766/?guest` で開くと、ログインせずにお試しモードで動く（localhost のときだけ）。

## 更新時の注意

スマホが古い CSS / JS を使い続けないよう、`index.html` で読み込むファイルに `?v=…` を付けています。
CSS・JS・データを変更したら、この値を新しくしてから公開してください。
